LISTA DE DEFINICIONES 10 ELEMENTOS

HTML
Lenguaje de marcado para estructurar páginas web.
CSS
Lenguaje usado para dar estilo a las páginas web.
Etiqueta
Elemento que define una parte del contenido en HTML.
Atributo
Información adicional agregada a una etiqueta.
Elemento
Componente formado por una etiqueta y su contenido.
Servidor
Equipo que almacena y entrega páginas web.
Navegador
Programa que interpreta y muestra páginas web.
Enlace
Elemento que permite navegar a otra página.
Formulario
Estructura para recolectar datos del usuario.
Semántica
Significado que aportan las etiquetas al contenido.
