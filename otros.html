OTRAS ETIQUETAS HTML

Conociendo diferentes etiquetas que podemos utilizar para crear páginas web.

← REGRESAR AL INICIO

01 — <details>

¿Para qué sirve? Crea una sección que el usuario puede abrir y cerrar para mostrar información adicional.

Ejemplo:

Ver información

Este texto aparece cuando se abre la sección.

02 — <summary>

¿Para qué sirve? Define el título visible de una sección creada con la etiqueta details.

Ejemplo:

¿Qué es HTML?

HTML es un lenguaje de marcado utilizado para crear páginas web.

03 — <dialog>

¿Para qué sirve? Crea una ventana de diálogo o cuadro emergente dentro de una página web.

Ejemplo:

Hola, esta es una ventana de diálogo.


04 — <blockquote>

¿Para qué sirve? Se utiliza para colocar una cita o texto tomado de otra fuente.

Ejemplo:

La educación es una de las herramientas más importantes para aprender.

05 — <ins>

¿Para qué sirve? Indica que una parte del texto ha sido agregada o insertada recientemente.

Ejemplo:

La página fue actualizada con nueva información.

06 — <del>

¿Para qué sirve? Indica que una parte del texto ha sido eliminada o ya no es válida.

Ejemplo:

Precio anterior: $500
Precio actual: $350

07 — <small>

¿Para qué sirve? Representa texto de menor importancia, como notas o aclaraciones.

Ejemplo:

Página creada para una práctica de HTML.
Última actualización: 23 de septiembre de 2026.

08 — <kbd>

¿Para qué sirve? Representa una tecla o combinación de teclas del teclado.

Ejemplo:

Para copiar utiliza Ctrl + C.

09 — <samp>

¿Para qué sirve? Representa una salida o resultado producido por un programa.

Ejemplo:

Resultado: Archivo guardado correctamente.

10 — <var>

¿Para qué sirve? Representa una variable matemática o utilizada en programación.

Ejemplo:

La fórmula es: x + 5 = 10

11 — <dfn>

¿Para qué sirve? Indica el término que se está definiendo dentro de un texto.

Ejemplo:

HTML es un lenguaje de marcado utilizado para crear páginas web.

12 — <bdi>

¿Para qué sirve? Aísla una parte del texto que puede tener una dirección diferente al resto.

Ejemplo:

Usuario: محمد

13 — <bdo>

¿Para qué sirve? Permite cambiar la dirección en la que se muestra un texto.

Ejemplo:

Este texto aparece de derecha a izquierda.

14 — <ruby>

¿Para qué sirve? Se utiliza para colocar anotaciones o pronunciaciones sobre determinados caracteres.

Ejemplo:

漢字 かんじ

15 — <rt>

¿Para qué sirve? Contiene la pronunciación o anotación que aparece dentro de una etiqueta ruby.

Ejemplo:

東京 とうきょう

16 — <rp>

¿Para qué sirve? Proporciona texto alternativo para navegadores que no soportan correctamente las anotaciones ruby.

Ejemplo:

漢 ( kan )

17 — <wbr>

¿Para qué sirve? Indica un posible punto donde una palabra puede dividirse cuando no existe suficiente espacio.

Ejemplo:

supercomputadora

18 — <picture>

¿Para qué sirve? Permite utilizar diferentes imágenes dependiendo del tamaño o características de la pantalla.

Ejemplo:

¿Para qué sirve? Permite crear un mapa de imagen con diferentes zonas interactivas.

Ejemplo:

¿Para qué sirve? Define una zona interactiva dentro de una imagen utilizada con la etiqueta map.
